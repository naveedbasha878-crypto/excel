# EXCEL SALES DASH BOARD
Sales Dashboard – Simple Report
1. Dashboard Overview
The Excel dashboard is created to analyze Sales Executive performance based on Total Sales, Target Hit %, and Away From Target %. The dashboard also provides an interactive location-wise analysis.

2. Location Slicer
A Location Slicer is used at the top of the dashboard to filter the complete dashboard based on different locations such as:

Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi and Surat.

When a location is selected, the related tables and charts are updated accordingly. In the current dashboard, Ranchi is selected.

3. Macro Option
A Macro/VBA option has been used to make the dashboard more interactive and user-friendly. The macro helps in controlling the dashboard elements and provides an easy way to interact with or refresh the dashboard based on the selected requirements.

This makes the dashboard more dynamic than a normal Excel report.

8. Overall Conclusion
The Excel dashboard provides an interactive view of sales performance using PivotTables, charts, slicers and macros. The Location Slicer allows users to analyze different locations, while the Macro option improves dashboard interaction. The bar chart identifies the top sales executive, the second table highlights the bottom sales executives, the pie chart displays Target Hit %, and the Away From Target chart compares performance against the target.

Overall, Syed Sohail is the top performer in the selected Ranchi dashboard, with the highest total sales of 1,363 and the highest Target Hit % of 272.60%.
